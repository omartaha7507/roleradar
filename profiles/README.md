# Profiles

Each person gets one folder here: `profiles/<name>/` (lowercase letters,
digits, `-` and `_`).

To create yours, copy `example/` to a new folder, for example `profiles/omar/`,
and edit the three files. Every folder except `example/` is gitignored, so your
personal data stays on your computer.

| File | What it holds | Who reads it |
| --- | --- | --- |
| `profile.yaml` | Rules: languages, years, target roles, locations, score lines | The filter and the ranker, for every job |
| `identity.md` | CV facts exactly as they should appear | The CV writer |
| `projects.md` | One section per project: what it proves, which roles it suits | The CV writer, to pick evidence |

Keep `profile.yaml` short and precise: it is read for every single job.
